## 🛠️ Công Nghệ & Quy Chuẩn Áp Dụng

### 1. Phương pháp & Mô hình Phân tích Thiết kế (OOSD)
- **Quy trình phân tích hướng đối tượng**:
  1. *Khảo sát nghiệp vụ & Yêu cầu hệ thống*: Đầu vào, xử lý, đầu ra, quy tắc nghiệp vụ, ma trận truy vết yêu cầu.
  2. *Mô hình hóa ca sử dụng (Use Case Modeling)*: Use Case tổng quát (Level 0), phân rã ca sử dụng (Level 1), đặc tả chi tiết (luồng chính, luồng thay thế, ngoại lệ, tiền/hậu điều kiện).
  3. *Mô hình hóa lớp phân tích (Analysis Class Diagram)*: Lớp thực thể (Entity Classes), thuộc tính, kiểu dữ liệu, các phương thức cốt lõi và quan hệ (kết tập, kết hợp, bội số).
  4. *Mô hình hóa hành vi*:
     - Biểu đồ trạng thái (State Machine): Vòng đời thực thể (`CHO_GIAO`, `GIAO_MOT_PHAN`, `DA_HOAN_TAT`...).
     - Biểu đồ hoạt động (Activity Diagram): Rẽ nhánh quyết định, điểm đồng bộ, xử lý ngoại lệ.
     - Biểu đồ tuần tự (Sequence Diagram): Tương tác 3 tầng `«boundary»`, `«control»`, `«entity»`.
  5. *Thiết kế chi tiết (Detailed Design)*: Biểu đồ lớp thiết kế 3 tầng (VOPC - View of Participating Classes), chi tiết phương thức, tham số và kiểu trả về.
  6. *Thiết kế cơ sở dữ liệu (Database Design)*: Mô hình thực thể liên kết (ERD) chuẩn 3NF, ràng buộc khóa chính [PK], khóa ngoại [FK], `CHECK`, `DEFAULT`, `UNIQUE`.
  7. *Kiến trúc & Điều hướng giao diện*: Kiến trúc 3 tầng (Presentation - Business Logic - Data Access), sơ đồ điều hướng Form (Form Navigation Diagram).

### 2. Ngôn ngữ & Nền tảng Kỹ thuật
- **Ngôn ngữ lập trình**: C# (.NET Framework 4.7.2 / 4.8), T-SQL, Python (đồ họa & tự động hóa sơ đồ).
- **Giao diện người dùng**: Windows Forms (WinForms) với kiến trúc phân tầng, DataGridView định dạng chuẩn, StatusStrip hiển thị trạng thái và số lượng bản ghi thời gian thực.
- **Truy xuất dữ liệu (Data Access)**: ADO.NET thuần với `SqlConnection`, `SqlCommand`, `SqlDataAdapter`, `SqlParameter` (chống SQL Injection), `SqlTransaction` (bảo toàn tính ACID).
- **Hệ quản trị CSDL**: Microsoft SQL Server với Stored Procedures bọc Transaction, Triggers kiểm soát logic toàn vẹn dữ liệu, Views nghiệp vụ và dữ liệu mẫu (Seed Data) hoàn chỉnh.
- **Công cụ thiết kế sơ đồ**: Diagrams.net / Draw.io, Visual Studio, SQL Server Management Studio (SSMS).

## 🚀 Hướng Dẫn Sử Dụng Kho Lưu Trữ

### 1. Clone repository
```bash
git clone https://github.com/NguyenPhiLong517/LAB_OOSD.git
cd LAB_OOSD
```

### 2. Mở và chỉnh sửa sơ đồ UML (`.drawio`)
- Mọi sơ đồ phân tích thiết kế đều có file `.drawio` tương ứng trong từng thư mục Lab (ví dụ: `Lab08/SoDo_Lab8_QL_CuaHangNuocGiaiKhat.drawio`, `Lab07/SoDo_Lab7_QuanLyNhanSu_SonDongA.drawio`, `gk/1/SoDo_BaoCao_GiuaKy_v2.drawio`).
- Bạn có thể mở trực tiếp bằng phần mềm [Draw.io Desktop](https://www.drawio.com/) hoặc truy cập [app.diagrams.net](https://app.diagrams.net/).

### 3. Cài đặt CSDL SQL Server
- Mỗi thư mục Lab chứa sẵn file script `.sql` hoàn chỉnh (bao gồm tạo bảng, khóa, trigger, stored procedure và dữ liệu mẫu).
- Mở file `.sql` trong **SQL Server Management Studio (SSMS)** và bấm **Execute (F5)**.

### 4. Mở giải pháp WinForms trong Visual Studio
- Các bài thực hành và đồ án có mã nguồn C# WinForms đi kèm trong file zip hoặc thư mục solution (`.sln` / `.csproj`).
- Mở bằng **Microsoft Visual Studio 2019 / 2022**, điều chỉnh chuỗi kết nối trong file `Database.cs` (hoặc `App.config`), sau đó nhấn **Ctrl + Shift + B** để biên dịch và **F5** để chạy ứng dụng.
